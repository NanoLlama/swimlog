⚡ Autofill Plates

Only serum, CSF, and plasma samples are autofilled — mAbs, controls and other types stay manual. Each sample is laid down as a side-by-side duplicate in columns 1–10; columns 11–12 are left for controls. In dither mode every block of N consecutive plates receives a proportional share of each group, so group membership is not confounded with plate. Well placement is a separate choice: keep groups in contiguous column blocks for hand pipetting, or scatter them once a robot is doing the work. Layouts are fully reproducible from the seed.

The variable balanced across plates.
Window size. N = all plates spreads each group over the whole run.
